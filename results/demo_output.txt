Why HMAC matters:
  - Plain SHA-256 proves INTEGRITY only: anyone can modify a file AND
    recompute a matching .sha256 checksum.
  - HMAC-SHA256 proves INTEGRITY + AUTHENTICITY: without the secret key,
    an attacker cannot forge a valid HMAC tag for a modified file.

==============================================================================
CONCEPT CHECK: HASHING vs ENCRYPTION (FOR VIVA)
==============================================================================
Hashing (e.g., SHA-256)  : One-way (irreversible), no secret key needed,
                           fixed 256-bit output -> guarantees INTEGRITY.
Encryption (e.g., AES)   : Two-way (reversible with decryption key),
                           output grows with input -> guarantees CONFIDENTIALITY.
