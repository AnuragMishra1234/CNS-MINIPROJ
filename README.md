# BCS703 Mini Project — Theme B: Hashing & File Integrity (`cns_hash_demo`)

> **SAFETY STATEMENT: DEMO ONLY - dummy data, local files only - BCS703 CNS Lab.**
> All scripts, commands, and outputs in this project operate exclusively on harmless dummy text files created inside `cns_hash_demo/`. No network access, no external package installs, and no real passwords, keys, accounts, or personal data are used anywhere.

---

## 1. Purpose

This beginner-friendly demonstration for **BCS703 (Cryptography and Network Security)** illustrates how cryptographic hashing (**SHA-256**) protects **file integrity**:

1. Generating a deterministic 256-bit (64-hex-character) fingerprint of a file.
2. Detecting even a single-character/single-bit modification (`sample_tampered.txt`) via digest mismatch and the **avalanche effect**.
3. Verifying integrity against a stored checksum file (`sample.txt.sha256`).
4. Demonstrating **fixed output size** regardless of input size and **determinism** across repeated runs.
5. Contrasting plain hashing (**integrity only**, one-way) with **HMAC-SHA256** (**integrity + authenticity** using a fake demo key) and with **encryption** (**confidentiality**, reversible).

## 3. Exact Commands to Run

Always run from inside the `cns_hash_demo/` directory:

### Run the Python Demo (Standard Library Only)
```powershell
cd cns_hash_demo
python hash_demo.py
```

### Run the Local OS Hash Verification (Windows PowerShell)
```powershell
Get-FileHash -Algorithm SHA256 sample.txt
Get-FileHash -Algorithm SHA256 sample_tampered.txt
```

*(If OpenSSL is installed on your machine, you can also run `openssl version`, `openssl dgst -sha256 sample.txt`, and `openssl dgst -sha256 sample_tampered.txt`; see `commands.md`.)*
